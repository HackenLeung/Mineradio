# Mineradio

Mineradio 是 Windows Electron 桌面音乐播放器，包含在线搜索与播放、本地音乐库、歌词舞台、粒子视觉、3D 歌单架、音频调节、桌面模式和自动更新。

当前维护仓库：[HackenLeung/Mineradio](https://github.com/HackenLeung/Mineradio)

## 本次更新内容（v1.4.0）

- **新增 MV 播放：** 小云音源的歌曲在底栏出现 MV 按钮，画面以中央 16:9 卡片呈现，支持 240P 到 1080P 切换和双击铺满。播放、进度、音量和切歌仍在底栏原位操作，系统媒体键与手机遥控同样可用。
- **MV 使用自带音轨：** 进入时暂停歌曲，退出时按原状态恢复；放完回到音频继续听歌，不自动串下一支。倍速对 MV 生效，音调位移对视频无效并置灰。

## v1.3.3 主要更新

- **本地歌曲起播更稳：** 播放前先准备输出设备和音频处理，再开始播放；不再在起播后重复切换输出设备。本地文件已经缓冲但进度卡在 0 秒时，会更快重建恢复，不再白等约 6 秒。
- **暂停歌词不再跳错歌：** 歌词请求、本地歌词匹配、延迟“暂无歌词”提示和翻译补偿都会确认仍属于当前歌曲；旧请求回来晚了会被丢弃，暂停时只保留当前歌曲当前行。
- **魔方隐藏不再失效：** 用魔方或托盘隐藏主窗口后，启动页的延迟事件不会再把窗口重新显示；主动从魔方、托盘或第二次启动应用时仍可正常打开。
- **启动更快、更不容易误报失败：** 111 个启动模块由逐个请求合并为一次请求；页面已可用时，即使个别资源加载慢也不会再误弹“主窗口加载失败”。合并端点异常会自动退回原加载方式。
- **已有能力继续保留：** 音源回退、长暂停恢复、智能过渡、局域网遥控和本地音乐匹配的既有行为不变。

## v1.3.2 主要更新

- **音乐库升级：** 新增舞台式 3D 音乐库封面墙；本地歌曲页支持搜索、定位当前歌曲、悬浮”下一首播放”和回到顶部，已添加文件夹、内嵌/同目录/自定义封面及在线匹配信息会继续保留。
- **沉浸式封面投递：** 点击音乐库歌曲卡片时，封面以 70% 起步沿抛物线飞入播放器，并与节奏联动的粒子、控制条玻璃动画和歌词舞台同步；旧动画回调不会干扰后续切歌，损坏封面直接回退普通播放。
- **听歌报告：** 新增本地月度与年度听歌报告、统计海报和导出入口；仅依据有效播放记录统计，数据不足时不展示虚构排名。
- **本地智能过渡：** 本地歌曲会正常预准备下一首，优先使用 sidecar、内嵌歌词和已匹配在线元数据确定人声进入点，避免从 0:00 生硬淡入或请求无效歌词地址。
- **播放模式恢复：** 重启和”恢复上次队列”会同步刷新播放模式图标与实际行为，异常存档值自动回退为顺序循环。
- **局域网遥控与诊断：** 手机可通过二维码或配对码遥控播放；遥控监听、来源校验、设备配对和媒体时钟冻结诊断均已加固。
- **稳定性与升级兼容：** 持续完善旧播放请求隔离、音源回退、长暂停恢复和音频代理；覆盖安装仍保留安装目录下的 `user-data` 与 `MineradioCache`。
- **歌词纹理显存优化：** 修复 high 档 1440p@1.5x 和 4K 分辨率下纹理压缩失效导致显存翻倍的 bug（从 270MB/60行 降到 ~130MB）；新增 GPU 显存探测和自适应质量降级，防止低端机 OOM 崩溃；Google Fonts 改为异步加载，墙内/断网环境首屏快 3-10 秒。

## 安装与覆盖升级

发布后从 [GitHub Releases](https://github.com/HackenLeung/Mineradio/releases) 下载并运行：

```text
Mineradio-1.4.0-Setup.exe
```

- 已安装用户应直接选择原安装目录，例如 `D:\Mineradio`，安装器会优先采用注册表记录的原路径。
- 正式用户数据位于 `<安装目录>\user-data`，包含设置、登录分区、Cookies、localStorage、IndexedDB、播放队列和本地库信息。
- 缓存位于 `<安装目录>\MineradioCache`，与 `user-data` 同级；`sessionData` 不会移动到缓存目录。
- 覆盖安装只替换程序文件，不复制、合并或移动上述两个目录。
- 默认卸载保留 `user-data` 和 `MineradioCache`；只有明确勾选“删除用户数据”时才删除。
- 旧目录存在但 `user-data` 缺失或不可写时，安装器会明确停止，不会创建空白数据冒充原用户资料。

## 核心能力

- 小云、小Q、小狗账号、搜索及歌单接入
- 3D 音乐库封面墙、本地歌曲搜索、当前歌曲定位和下一首播放
- 本地文件夹音乐库、二级歌单、内嵌/同目录封面与歌词
- 本地歌曲在线匹配、持久歌词缓存、封面投递和当前歌曲定位
- MV 播放（小云音源）、清晰度切换和双击铺满
- 智能过渡、倍速/音调、均衡器、节奏分析和电影镜头
- 歌词舞台、桌面歌词、歌词布局、粒子视觉和 3D 歌单架
- Wallpaper Engine 原生联动、桌面锁定、托盘和悬浮遥控器
- Home、继续听、每日推荐、月度/年度听歌报告、平台歌单和长列表虚拟化
- GitHub Releases 更新检测、完整安装包和安全安装/卸载流程

## 已知边界

- 第三方接口、账号状态、地区版权或会员权限不可用时，搜索、歌单、歌词或在线播放可能失败。
- MV 只有小云音源提供，小Q 与小狗没有对应接口；小云侧没有 MV 的歌曲按钮为灰色。MV 音轨不接入音频处理链，均衡器、频谱和音调位移对 MV 无效。
- 桌面歌词、透明窗口、Wallpaper Engine 和桌面锁定受 Windows、显卡驱动、桌面软件和安全软件影响。
- 安装包目前未做商业代码签名，Windows SmartScreen 可能显示未知发布者，请只从当前维护仓库下载。

## 开发运行

```powershell
npm install
npm start
npm run build:win
```

桌面版由 Electron 主进程加载本地服务。前端运行时代码位于 `public/js/modules/`，入口由 `public/js/index-loader.js` 按顺序加载；不要再把当前模块化实现回退成旧版单文件架构。

常用检查：

```powershell
git diff --check
node scripts/quick-check.js
npm run build:win
```
